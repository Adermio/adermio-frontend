# R4 — Relecture native DE : blog + pages juridiques

Relecteur : rédacteur-correcteur natif allemand (santé-beauté SEO + juridique web). Date : 30/09/2026.
Référence : `tests/i18n/de/GLOSSAIRE_DE.md`. Sources FR vérifiées phrase par phrase : `blog/*.html`, `conditions.html`, `confidentialite.html`, `mentions-legales.html`, `sources.html`.
Aucun fichier du site modifié.

Constat général : la traduction est de bonne qualité, naturelle dans l'ensemble, fidèle au FR, en « Sie » partout, sans langage médical côté Adermio (vérifié par recherche : aucun *Diagnose / Befund / Patient / Therapie / heilen / Prognose* appliqué à Adermio ; les *Behandlung* restants concernent le traitement médical de l'utilisateur, ce qu'autorise le glossaire). Faits dermatologiques justes. Pas de restes de français. `lang="de"`, canonical et hreflang corrects sur les 9 pages. Les corrections ci-dessous visent surtout des tournures calquées sur le français, quelques ambiguïtés et la cohérence avec le glossaire.

Gravité : **bloquant** = faux / trompeur / choquant pour un lecteur allemand ; **important** = faute, ambiguïté, calque ou écart au glossaire visible ; **confort** = amélioration de style ou de SEO.
