## 3. Glossaire : entrées à corriger ou à compléter

| entrée | constat | proposition |
|---|---|---|
| parapharmacie → `Drogerie` | En Allemagne, les marques de dermocosmétique (La Roche-Posay, Avène, CeraVe…) se vendent surtout en pharmacie et en ligne ; la *Drogerie* (dm, Rossmann) propose d'autres gammes. Le site dit à juste titre *Apotheke*. | `Apotheke (auch online) / Drogerie` selon la marque ; par défaut : *Apotheke* |
| satisfait ou remboursé → `Geld-zurück-Garantie` | Le mot *Garantie* est un terme juridique en Allemagne (§ 443/479 BGB) : il oblige à préciser des conditions dans la déclaration. Non utilisé sur le site aujourd'hui. | Ajouter la note « seulement avec des conditions écrites (validation juriste) » ; sinon `Geld zurück, wenn Sie nicht zufrieden sind` |
| acné rétentionnelle → `Mitesser-Akne` | Acceptable dans le langage courant ; le terme dermatologique courant est *komedonale Akne* (Acne comedonica). | Garder `Mitesser-Akne` dans le texte courant, ajouter `(komedonale Akne)` dans les blogs |
| « zone » (nom générique) | Entrée absente : le site alterne *Bereich* et *Zone*. | `zone` = *Bereich* ; *Zone* uniquement dans *T-Zone*, *U-Zone*, *Zone für Zone* |
| entrées manquantes | Des termes récurrents ne sont pas figés : *Pflegeplan*, *Premium*, *Vergleichsanalyse*, *Score*, *observance*, *suivi*, *Profil* (photo), *Méthode clinique*, *Diagnostic Expert*. | Ajouter : observance = *Regelmäßigkeit* ; suivi = *Begleitung* (jamais *Tracking* dans le texte courant) ; analyse comparative = *Vergleichsanalyse* ; « plan de soins » = *Pflegeroutine* (jamais *Pflegeplan*) ; « premium » (analyse web) = *Komplettanalyse*, *Premium* réservé à l'abonnement de l'app ; « méthode clinique » = *wissenschaftlich fundiert* ; « diagnostic expert » = *KI-Hautanalyse* |

Aucune entrée du glossaire n'est fausse sur le fond ; les autres choix (*Komplettanalyse*, *zweite Runde*, *28-Tage-Check*, *schwarze/weiße Mitesser*, *Pickelmale*, *LSF*, *Ausprägung leicht/mittel/stark*, *Erfahrungen*) sont bons et bien appliqués sur le site.

## 4. Points conformes (pour mémoire)

- *Komplettanalyse* : utilisé de façon cohérente sur `home`, `feedback`, `premium`, `success` (sauf le titre *Adermio Premium*, voir § 1).
- *kostenlose Hautanalyse* : cohérent (bouton des blogs, JSON-LD, FAQ).
- *zweite Runde / Runde 2 / 28-Tage-Check / Zwischenstand nach 28 Tagen* : cohérents sur `bilan`, `second-cycle`, `premium-second-cycle`, `analysis-in-progress-second-cycle`, `nutzungsbedingungen`.
- *schwarze / weiße Mitesser*, *Pickelmale*, *Ausprägung*, *leichte / mittelschwere*, *Pusteln*, *entzündete Knötchen (Papeln)* : conformes.
- Formats : `5,99 €`, `0,18 €`, `98,5 %`, `107.840`, `2.000`, `4,4/5`, `7. März 2026`, `10.07.2026`, guillemets „…“ : conformes (sauf les exceptions JS du § 1).
- Menu (Startseite · Analyse starten · Über uns · Blog · Kontakt) et libellés du pied de page (Nutzungsbedingungen · Impressum · Datenschutz · Alle Rechte vorbehalten) : identiques sur toutes les pages (sauf les exceptions du § 1).
- Traitement de l'utilisateur (`Behandlung gegen Akne?`, `Aktuelle Medikamente`, `hautärztliche Behandlungen`) : conforme à l'exception prévue par le glossaire.
